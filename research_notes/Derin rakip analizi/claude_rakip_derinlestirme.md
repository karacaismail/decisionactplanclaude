## Q1. Turkish public tenders and KİK decisions for strategic plan, performance management, scorecard and OKR software

### Takeaway
No public tender or KİK board decision that buys "stratejik plan yazılımı", "kurumsal karne", or "OKR yazılımı" by that name was found in open sources. The EKAP search (including the KİK decision search, which now redirects to EKAP v2) returns "HUMAN_VERIFICATION_REQUIRED" to automated queries, so it was not searched, and the CAPTCHA was not bypassed. The evidence that does exist shows two things. First, public bodies buy this capability inside broad ERP or "yönetim bilgi sistemi" contracts or build it themselves. Second, a new 2026 tender shows municipalities buying strategy consulting as a service.

### Cited Findings
- Access check (16 November 2026): `ekap.kik.gov.tr/EKAP/Vatandas/kurulkararsorgu.aspx` now returns HTTP 302 to `ekapv2.kik.gov.tr`. The EKAP v2 tender search API answered HTTP 428 with code "HUMAN_VERIFICATION_REQUIRED". The ilan.gov.tr search API answered HTTP 403 to scripted requests. So no structured search of tenders or KİK decisions was possible — [EKAP v2](https://ekapv2.kik.gov.tr/)
- **Zeytinburnu Belediyesi (İstanbul), İKN 2026/2247583**: "Kurumsal Hizmet Stratejisi Geliştirmeye Yönelik Uygulama, Saha Araştırmaları, Rehberlik, Analiz ve Raporlama Hizmeti". ### Inferences
- Public buyers rarely tender "strategic plan software" as a standalone item. It comes bundled in municipal ERP (SAMPAŞ, TeraMIS, SaySis, Birsav) or university quality systems (UNİKYS, BKYS, STARSİS), or it is built in-house. A standalone vendor would need to sell through these ERP suppliers or into the consulting line, not through a dedicated tender.
- The Zeytinburnu tender shows a second public channel: strategy consulting bought as a one-year service at lowest price. This is where a "consultant plus Karar Atlası" bundle could bid, but price-only evaluation favours cheap manual consulting.

### Gaps

- The STARSİS and SAMPAŞ strategy module vendors and prices are unknown.
- Zeytinburnu's estimated cost is not public until award.

## Q4. User reviews with substance (global tools) and Turkish user reviews

### Takeaway
